# Undercover Billionaire - Financial Fraud Tracker

A cinematic, suspenseful financial dashboard application inspired by the perspective of an undercover billionaire investigating corporate malfeasance. The app features a dark, secretive UI with glowing red financial codes and real-time fraudulent transaction logs, designed for an intense investigative experience.

## Features
- **Dark Mode UI:** A secretive, high-contrast interface suitable for late-night corporate bullpen environments.
- **Fraudulent Transaction Logs:** Glowing red data feeds displaying suspicious activities.
- **Investigative Dashboard:** Minimalist, data-heavy displays capturing a suspenseful mood.
- **Cross-Platform:** Runs seamlessly on Web, macOS, Windows, Linux, iOS, and Android.

## Tech Stack
- Framework: Flutter
- Language: Dart
- UI/UX: Custom Material widgets with dark/red color schemes.

## Setup Instructions
1. Ensure you have Flutter installed.
2. Clone this repository.
3. Run `flutter pub get` to fetch dependencies.
4. Run `flutter run` to launch the application on your preferred platform.
